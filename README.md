# 🌦️ Weather App

A simple and responsive Weather App built using HTML, CSS, and JavaScript. It provides real-time weather information for any city using a weather API.

#🚀 Features

-  Search weather by city name
-  Displays current temperature
-  Shows humidity
-  Shows wind speed
- Displays weather condition and icon
- Responsive design for mobile and desktop
-  Fast and easy to use

# Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Weather API
